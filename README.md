https://hiyawtaken.github.io/portfolio/

A portfolio styled after a blocky game's menus. Plain HTML/CSS/JS, served by GitHub Pages with no build step.

- Edit content in `assets/content.js`.
- The background landscape, item icons, logo, and sounds are generated in code (`assets/world.js`, `assets/sprites.js`, `assets/logo.js`, `assets/sound.js`).
- Font: [Minecraftia](https://andrewtyler.gumroad.com/l/minecraftia) by Andrew Tyler, free for personal use.
